# API overview

The interactive reference is generated by FastAPI: Swagger UI at `/docs`, ReDoc at `/redoc`. A snapshot of the schema is kept in [`docs/openapi.json`](../openapi.json) and checked by a contract test, so it always matches the code. After an intended API change run `make openapi` and review the diff.

Every route except `/health`, `/health/ready`, `/auth/login` and `/auth/refresh` needs `Authorization: Bearer <access token>`. A user who must still choose a new password can only reach `/auth/me` and `/auth/change-password`.

## Errors

Errors are JSON with a `detail` message. Provider failures are reported with safe messages that do not include provider internals: 401 for a missing or expired token, 403 when the role or state does not allow the call, 404 for something the caller may not see, 422 for invalid input and 503 when a dependency (database, provider, JWT secret) is not available.

## Streaming

`/ask` and `/chat` accept `"stream": true` and answer with server-sent events: `delta` events carrying text, then one `done` event with usage (and the stored ids for chat), or an `error` event.
